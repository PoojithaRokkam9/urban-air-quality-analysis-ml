# Urban Air Quality Analysis and Pollution Level Prediction

## Project Overview
This project analyzes air quality data from different cities and states in India and predicts PM2.5 levels using machine learning.

## Dataset
Source: Government of India Open Government Data Platform (CPCB)

https://www.data.gov.in/catalog/real-time-air-quality-index

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Target
PM2.5

## Files
- `Rokkam_PoojithaKumari_UrbanAirQualityAnalysis.ipynb` - Project code and analysis
- `requirements.txt` - Python libraries required
- `Rokkam_PoojithaKumari_ProjectReport.docx` - Project report

## How to Run
Open the `.ipynb` file in Google Colab or Jupyter Notebook and run the cells in order.
